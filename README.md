# 擁車還是叫車

比較五種用車方式的花費：新車、中古車、訂閱車、Uber 叫車、叫車＋租車。

## 可以做什麼

- 選車款，或自己輸入車價、油耗、稅金
- 設定使用年數、每月預算、頭期款、停車費
- 依每天里程和假日出遊次數，算出油錢、Uber 車資和租車費
- 每種方式分成「起始資金」「每月」「每年」「期末拿回」來算
- 用折線圖看累積支出，用表格比較淨成本

## 怎麼用

直接用瀏覽器開啟 `index.html`。不需要安裝任何東西。

如果要放上網，可以在 GitHub 的 Settings → Pages 選擇 `main` 分支，網址會是 `https://timhong01.github.io/getcars/`。

## 資料說明

車價、Uber 費率、稅金是 2026 年 10 月的參考值。訂閱月費和 Tesla 新車價是估計值。看到實際報價後，請在網頁上直接修改數字。
